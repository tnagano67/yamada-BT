# 自学自習モード 詳細設計書

## 概要

自学自習モードは、朝テストの補完として生徒が**自分のペースで**単語を練習・復習し、グレード昇格を目指すための機能。4択問題のみで構成し、スキマ時間（2〜3分）で完結する手軽さを重視する。

---

## 1. 練習モードの設計

### 1.1 モード構成（3種類）

| モード | 目的 | 問題数 | 所要時間 | 出題範囲 |
|--------|------|:------:|:--------:|---------|
| **クイック練習** | 日常的な語彙定着 | 10問 | 2〜3分 | 現在のグレード範囲 |
| **苦手克服** | 間違えた問題の復習 | 10問 | 2〜3分 | 苦手リストから |
| **昇格チャレンジ** | グレード昇格判定 | 10問 | 3分 | 昇格対象グレード範囲 |

### 1.2 クイック練習

日常の学習で最も頻繁に使うモード。

**出題ロジック:**
- 現在のグレード範囲から10問をランダム出題
- 新出グレード（例: E3）なら、そのグレードの50語から出題
- 復習グレード（例: E5）なら、累計範囲（No.1〜200）からまんべんなく出題
- 過去に間違えた問題を**30%の確率で優先出題**（残り70%はランダム）

**セッション中の再出題:**
- 1セッション内で間違えた問題は、残りの問題の後に**もう1回だけ再出題**する
- 例: 10問中3問間違えた場合 → 最後に3問が追加され、合計13問になる
- 再出題での正誤は昇格判定には含まない（練習としての位置づけ）

**1セッション10問の根拠:**
- 4択問題1問あたり約10〜15秒（読み→判断→タップ）
- 10問 = 約2分、結果確認を含めて2〜3分で完結
- 高校生が休み時間や通学中にサッと取り組める量
- 短すぎると達成感がない、多すぎると負担感が出るバランス

### 1.3 苦手克服モード

間違えた問題を集中的に復習するモード。

**出題ロジック:**
- 苦手リスト（後述セクション4）から、定着度が低い順に10問を選出
- 苦手リストが10問未満の場合は、リストの全問題を出題
- 苦手リストが空の場合は「苦手な問題はありません」と表示し、クイック練習を推奨

**復習間隔（修正Leitnerシステム、4択向けに調整）:**

| レベル | 復習間隔 | 意味 |
|:------:|:--------:|------|
| Lv0 | 即時（同日中） | 初回不正解。今日中にもう一度 |
| Lv1 | 1日後 | まだ不安定。翌日に確認 |
| Lv2 | 3日後 | 短期記憶には入った |
| Lv3 | 7日後 | 中期記憶への移行期 |
| Lv4 | 14日後 | ほぼ定着。最終確認 |
| Lv5 | 定着完了 | 苦手リストから卒業 |

- 正解 → レベルを1つ上げる
- 不正解 → Lv0に戻す（ただしLv3以上からはLv1に戻す。心理的負荷軽減）
- Lv5に達した問題は苦手リストから除外（定着完了）

### 1.4 昇格チャレンジ（本番テスト）

グレード昇格を判定する公式テスト。

**仕様:**
- 対象グレード範囲から10問を出題
- 80%以上（8問以上正解）で「合格」
- 3回連続合格でグレード昇格
- 不合格の場合、連続カウントを0にリセット

**朝テストとの関係:**
- 朝テストの結果も昇格チャレンジと同等に扱う
- つまり「朝テストで80%以上」も連続カウントに加算される
- 朝テスト2回合格 + 自学自習の昇格チャレンジ1回合格 = 昇格、も成立する
- 生徒は朝テストだけでも昇格可能、自学自習だけでも昇格可能、組み合わせも可能

**受験条件:**
- 制限なし。いつでも自由に受験可能
- ただし、1日の受験回数は**3回まで**（乱用防止）
- 回数制限を超えた場合は「今日はここまで。明日また挑戦しよう！」と表示
- 不合格後の即時再挑戦も可能（クールタイムなし。テンポ重視）

**設計判断 -- 受験条件をフリーにする理由:**
- 「練習で○○%以上を取らないと受験できない」とすると、生徒が面倒に感じてアプリを開かなくなるリスク
- 不合格になっても「3回連続がリセットされるだけ」なので、失敗のコストが低い
- むしろ「気軽に挑戦 → 不合格 → 苦手が明確に → 復習」の流れが自然に生まれる
- 1日3回の制限により、無限ガチャ的な試行は防止

## 2. 4択問題の工夫

### 2.1 誤答選択肢の生成ロジック

4択問題の質は誤答選択肢（ディストラクター）の質で決まる。消去法で安易に解ける問題を防ぐため、以下の3層戦略で選択肢を生成する。

**選択肢生成の3層戦略:**

```
正解: 1つ（正答の単語/意味）
誤答1: 同カテゴリの紛らわしい選択肢（意味が近い or 形が似ている）
誤答2: 同グレード範囲内のランダムな選択肢
誤答3: 同グレード範囲内のランダムな選択肢
```

**層1: 紛らわしい選択肢（ディストラクター）の生成方法:**

(a) **意味的に近い単語**（同じ意味カテゴリから選ぶ）
- 例: 正解「accept（受け入れる）」→ 誤答に「receive（受け取る）」「agree（同意する）」
- 単語帳データに意味カテゴリタグ（動作、感情、場所、時間 等）を付与し、同カテゴリから選出

(b) **形が似ている単語**（スペルが類似）
- 例: 正解「affect（影響する）」→ 誤答に「effect（効果）」
- レーベンシュタイン距離が3以下の単語を候補とする

(c) **生徒が過去に混同した単語**
- 回答履歴から「Aを聞かれてBと答えた」パターンを蓄積
- そのパターンがある場合、Bを誤答選択肢に優先的に採用
- 初期段階（データ不足）では(a)(b)のみで生成

**層2・層3: ランダム選択肢:**
- 同グレード範囲内から、正解・誤答1と重複しない単語をランダム選出
- 明らかに品詞が異なる選択肢は避ける（動詞の意味を聞いているのに名詞だけの選択肢を入れない）

### 2.2 選択肢のバリエーション

**同じ問題でも毎回選択肢を変える:**
- 正解以外の3つの誤答選択肢を毎回ランダムに再生成
- 選択肢の表示順序も毎回シャッフル
- これにより「2番目が正解」のような位置記憶による正解を防止

**出題方向のバリエーション:**

| 出題方向 | 問題文 | 選択肢 |
|---------|--------|--------|
| 英→和 | 「accept」の意味は？ | 受け入れる / 受け取る / 断る / 送る |
| 和→英 | 「受け入れる」を英語で？ | accept / receive / refuse / send |
| 意味→単語 | 「人を快く迎え入れること」に最も近い単語は？ | accept / reject / ignore / attend |

- 同じ単語に対して出題方向を変えることで、多角的な定着を促す
- 出題方向はセッションごとにランダムに決定（英→和 60%、和→英 30%、意味→単語 10%）

### 2.3 消去法対策

4択では「正解を知らなくても明らかに違う選択肢を消去して正解できる」問題が発生しがちなため、以下の対策を行う。

**対策一覧:**

| 対策 | 内容 |
|------|------|
| **品詞の統一** | 選択肢4つの品詞を揃える（全て動詞、全て名詞 等） |
| **意味の近接性** | 少なくとも1つは意味が近い紛らわしい選択肢を含める |
| **文字数の均一化** | 選択肢の文字数を概ね揃える（正解だけ極端に長い/短いを避ける） |
| **既知語の混入** | 生徒が過去に正解した単語も誤答選択肢に使う |
| **正解位置の均等化** | 正解が1〜4番目に均等に配置されるようバランス管理 |

**正解位置のバランス管理:**
- 10問のセッション内で、正解位置が1〜4番目にそれぞれ2〜3回ずつ配置
- 同じ位置が3回以上連続しないように制御

```
  │     │

```

### 3.2 「今日のおすすめ学習」ロジック

ホーム画面のトップに1枚のカードで表示。タップするとそのモードに直行する。

**優先順位（上から順に評価、最初にヒットしたものを表示）:**

| 優先度 | 条件 | 表示メッセージ例 | 遷移先 |
|:------:|------|----------------|--------|
| 1 | 昇格チャレンジ連続2回合格中 | 「あと1回で昇格！挑戦しよう」 | 昇格チャレンジ |
| 2 | 復習期限切れの苦手問題が5問以上 | 「12個の苦手単語が復習待ち」 | 苦手克服 |
| 3 | 今日まだ自学自習をしていない | 「今日のクイック練習をやろう」 | クイック練習 |
| 4 | 直近の昇格チャレンジで不合格 | 「苦手を復習してリベンジしよう」 | 苦手克服 |
| 5 | 上記いずれでもない | 「10問だけやってみよう」 | クイック練習 |

**メッセージのトーン:**
- 命令調を避け、提案調にする（「やりなさい」ではなく「やってみよう」）
- 短く具体的に（「12個の苦手単語が待っています」のように数値を含める）

### 3.3 学習セッションの区切り方

**問題数制を採用（時間制ではない）:**

| 項目 | 仕様 |
|------|------|
| 基本単位 | 1セッション = 10問 |
| 制限時間 | なし（自分のペースで解答） |
| セッション終了 | 10問解き終わったら自動で結果画面へ |
| 連続セッション | 結果画面の「もう1セット」ボタンで連続可能 |
| 1日の上限 | なし（好きなだけ学習可能） |

**時間制を採用しない理由:**
- 4択問題は1問10〜15秒で解けるため、時間制限がなくても自然に2〜3分で終わる
- 制限時間があると焦って消去法に頼りがちになる
- 自分のペースで考えられることで、正しい思考プロセスを促す
- ただし、1問あたり30秒経過で「ヒント」ボタンを表示（任意利用）

**ヒント機能:**
- 30秒経過で「ヒントを見る」ボタンが出現
- タップすると、正解の最初の1文字（英語の場合）or 品詞（日本語の場合）を表示
- ヒント使用時も正解はカウントするが、苦手リストへの影響はヒント未使用時より低い重みづけ

## 4. 間違えた問題の管理

### 4.1 苦手リストの記録・分類

**苦手リストへの追加条件:**
- クイック練習、苦手克服、昇格チャレンジのいずれかで不正解 → 自動追加
- 朝テストで不正解 → 自動追加
- 既に苦手リストにある問題で不正解 → レベルをリセット（Lv0に戻す）

**苦手リストのデータ構造:**

```
ReviewItem {
  id: UUID
  student_id: UUID
  word_id: UUID              // 単語帳の単語ID
  subject: "english" | "japanese"
  grade_id: string           // 所属グレード（E1, J3 等）
  leitner_level: 0-5         // 修正Leitnerレベル
  next_review_date: date     // 次回復習予定日
  total_attempts: number     // この単語の総回答数
  correct_count: number      // 正解数
  wrong_count: number        // 不正解数
  last_wrong_answer: string  // 最後に選んだ誤答（混同パターン分析用）
  created_at: datetime       // 苦手リスト追加日
  updated_at: datetime
}
```

**分類表示（苦手リスト画面）:**

| 分類 | 条件 | 表示 |
|------|------|------|
| 要復習（赤） | Lv0〜Lv1、かつ復習期限到来 | 「今すぐ復習しよう」 |
| もう少し（黄） | Lv2〜Lv3 | 「あと少しで定着」 |
| ほぼ定着（緑） | Lv4 | 「最終確認待ち」 |

- Lv5に到達した問題は苦手リストから自動除外（「定着完了」として非表示）
- 定着完了した問題は「克服した単語」タブで閲覧可能（達成感の可視化）

### 4.2 苦手リストの表示と導線

**苦手リスト画面の構成:**

```
[苦手リスト]
  │
  ├── サマリー: 「苦手: 12語 / 定着完了: 45語」
  │
  ├── フィルター: [全て] [英語] [日本語] [要復習のみ]
  │
  ├── 単語カード一覧（定着度が低い順に表示）
  │     ├── 単語名 + 意味
  │     ├── 定着度バー（Lv0〜5を5段階で可視化）
  │     ├── 次回復習日
  │     └── 正解率（正解数/総回答数）
  │
  ├── [まとめて復習する] ボタン → 苦手克服モードへ
  │
  └── [克服した単語] タブ
        └── 定着完了した単語の一覧（達成感の可視化）
```

**ホーム画面からの導線:**
- ホーム画面に「苦手: ○語」のバッジ表示
- 苦手が5語以上で「おすすめ学習」に苦手克服が表示される
- 昇格チャレンジ不合格後に「まず苦手を復習しませんか？」の誘導

### 4.3 「定着した」の判断基準

```
定着完了の条件:
  修正Leitnerシステムで Lv5 に到達
  （= 正解を重ねて Lv0 → Lv1 → Lv2 → Lv3 → Lv4 → Lv5 と昇格）

実質的な意味:
  最短で「当日 → 翌日 → 3日後 → 7日後 → 14日後」の5回連続正解
  間隔を空けて5回正解することで、長期記憶への定着を確認
```

**補足ルール:**
- 正解した問題もクイック練習では低確率（10%）で再出題される（忘却防止）
- 定着完了後30日以上経過した問題で再度不正解が出た場合、Lv2として苦手リストに復帰

## 5. グレード昇格との連動

### 5.1 昇格の流れ

```
[日常学習]
  朝テスト + クイック練習 + 苦手克服
    │
    ▼
[昇格チャレンジに挑戦]（任意のタイミングで）
    │
    ├── 合格（80%以上）→ 連続カウント +1
    │     │
    │     ├── 1回目合格 → 「あと2回！」
    │     ├── 2回目合格 → 「あと1回！」
    │     └── 3回目合格 → 昇格！
    │           │
    │           └── 昇格演出 → 新グレード表示 → バッジ判定
    │
    └── 不合格（80%未満）→ 連続カウント リセット
          │
          └── 間違えた問題を苦手リストに追加
              → 「苦手を復習してリベンジしよう」
```

### 5.2 朝テストと昇格チャレンジの関係

**統合カウント方式を採用:**

| テスト | 昇格カウント対象 | 条件 |
|--------|:--------:|------|
| 朝テスト | 対象 | 現在のグレード範囲から出題された回で80%以上 |
| 昇格チャレンジ | 対象 | 80%以上 |

- 朝テストと昇格チャレンジは区別なく連続カウントに加算される
- 例: 月曜の朝テスト合格(1回目) → 火曜の朝テスト合格(2回目) → 火曜夜に昇格チャレンジ合格(3回目) → **昇格！**
- 例: 昇格チャレンジ合格(1回目) → 朝テスト不合格 → **リセット（0回目に戻る）**

**朝テストが対象にならないケース:**
- 朝テストの出題範囲が現在のグレード範囲と異なる場合（教員が別範囲を指定した場合）
- この場合、朝テストの結果は昇格カウントに含まれない旨を結果画面に表示

**この設計のメリット:**
- 朝テストだけでも昇格可能 → 自学自習をしない生徒も進める
- 自学自習で積極的に挑戦すれば早く昇格可能 → 意欲の高い生徒に報いる
- 別々に管理する必要がなくシンプル

### 5.3 昇格演出

昇格時は特別な演出で達成感を演出する。

```
[昇格演出の流れ]（3〜4秒間）

1. 画面中央に大きく「グレードアップ！」と表示
2. 新グレード名とカラーを表示（例: 「E3 ワードファイター → E4 ワードスター」）
3. 新グレードのカラーバッジがアニメーションで登場
4. 獲得バッジがあれば同時表示（「昇格テスト一発合格」等）
5. 「次のグレードへ進もう！」ボタンでホームに戻る
```

- 演出は短めに（長いと繰り返し見ると煩わしくなる）
- スキップ可能（画面タップで即座にホームへ）

## 6. スキマ時間での利用設計

### 6.1 2〜3分で完結するセッション設計

| 要素 | 設計 |
|------|------|
| 起動→学習開始 | ワンタップで最速到達。ホーム画面の「おすすめ」をタップするだけ |
| 1セッション | 10問固定。4択なので1問10〜15秒、合計2分前後 |
| 結果確認 | スコアと間違えた問題を30秒で確認 |
| 合計 | 2〜3分 |

**最速フロー:**
```
アプリ起動 → 「おすすめカード」タップ → 10問解答 → 結果確認 → 終了
（タップ数: 起動1回 + おすすめ1回 + 問題10回 + 結果確認1回 = 13タップ）
```

### 6.2 中断・再開の仕組み

**中断の扱い:**
- セッション中（10問の途中）にアプリを閉じた場合、進捗を保存
- 次回アプリ起動時に「前回の続きがあります。再開しますか？」と表示
- 「再開する」→ 中断した問題から再開
- 「最初からやり直す」→ セッションを破棄して新規開始

**保存データ:**
```
SessionState {
  session_id: UUID
  mode: "quick" | "weakness" | "promotion"
  grade_id: string
  questions: Question[]      // 出題済みの問題リスト
  current_index: number      // 現在の問題番号（0-indexed）
  answers: Answer[]          // 回答済みの回答
  started_at: datetime
  suspended_at: datetime?    // 中断日時
}
```

**中断データの有効期限:**
- 中断から**24時間以内**は再開可能
- 24時間を超えた場合は自動破棄（古いセッションを引きずらない）
- 昇格チャレンジの中断データも同様の扱い

### 6.3 オフライン対応

**基本方針: オフラインファーストで設計**

学校PCやスマホで通信が不安定な場面（通学中、校内のWi-Fi混雑等）を想定し、基本的な学習はオフラインでも可能にする。

| 機能 | オフライン | 備考 |
|------|:----------:|------|
| クイック練習 | 可 | 問題データをローカルにキャッシュ |
| 苦手克服 | 可 | 苦手リストをローカルに保持 |
| 昇格チャレンジ | 可 | ただし結果の反映はオンライン復帰後 |
| 苦手リスト閲覧 | 可 | ローカルデータを表示 |
| ダッシュボード | 不可 | サーバーデータが必要 |

**同期の仕組み:**
- オフライン中の学習結果はローカルに蓄積
- オンライン復帰時に自動でサーバーと同期
- 同期中は「同期中...」のインジケーターを表示
- 同期完了後に昇格判定を実行（オフライン中に3回連続合格していた場合、同期時に昇格）

**キャッシュ戦略:**
- 現在のグレード範囲 + 前後1グレードの単語データを事前キャッシュ
- 苦手リストの全データをローカルに保持
- キャッシュサイズは1グレード50語 x 3グレード = 150語程度（数KB）で軽量

## 7. データモデル

### 7.1 学習セッションテーブル

```
study_session {
  id: UUID (PK)
  student_id: UUID (FK)
  mode: "quick" | "weakness" | "promotion"
  subject: "english" | "japanese"
  grade_id: string           // 対象グレード（E3, J5 等）
  question_count: number     // 出題数
  correct_count: number      // 正解数
  score_percentage: number   // 正答率（%）
  is_passed: boolean?        // 昇格チャレンジの場合のみ（80%以上で合格）
  started_at: datetime
  completed_at: datetime?
  is_suspended: boolean      // 中断中フラグ
  session_state: JSON?       // 中断時のセッション状態
}
```

### 7.2 回答詳細テーブル

```
study_answer {
  id: UUID (PK)
  session_id: UUID (FK)
  word_id: UUID (FK)         // 出題された単語
  question_direction: "en_to_ja" | "ja_to_en" | "meaning_to_word"
  correct_option: string     // 正解選択肢
  selected_option: string    // 生徒が選んだ選択肢
  all_options: string[]      // 表示された4つの選択肢
  is_correct: boolean
  hint_used: boolean         // ヒントを使用したか
  time_spent_ms: number      // 回答にかかった時間（ミリ秒）
  answered_at: datetime
}
```

### 7.3 昇格カウントテーブル

```
promotion_progress {
  id: UUID (PK)
  student_id: UUID (FK)
  subject: "english" | "japanese"
  target_grade_id: string    // 昇格先グレード
  consecutive_passes: number // 連続合格回数（0〜3）
  last_pass_at: datetime?    // 最後の合格日時
  last_fail_at: datetime?    // 最後の不合格日時
  attempts_today: number     // 今日の昇格チャレンジ受験回数
  updated_at: datetime
}
```

### 7.4 苦手リストテーブル（再掲・詳細版）

```
review_item {
  id: UUID (PK)
  student_id: UUID (FK)
  word_id: UUID (FK)
  subject: "english" | "japanese"
  grade_id: string
  leitner_level: 0-5
  next_review_date: date
  total_attempts: number
  correct_count: number
  wrong_count: number
  last_wrong_answer: string?
  graduated_at: datetime?    // Lv5到達日時（定着完了）
  created_at: datetime
  updated_at: datetime
}
```

## 8. 実装優先度

| 優先度 | 機能 | 理由 |
|--------|------|------|
| **P0** | クイック練習（10問4択） | 最も基本的な自学自習機能 |
| **P0** | 昇格チャレンジ（3回連続合格で昇格） | グレード制度のコア機能 |
| **P0** | 朝テストと昇格カウントの統合 | 昇格の仕組みに不可欠 |
| **P0** | 4択問題の自動生成（基本版） | ランダム選択肢 + 位置シャッフル |
| **P1** | 苦手リスト + 苦手克服モード | 復習による定着促進 |
| **P1** | 修正Leitnerシステム | 効率的な復習間隔管理 |
| **P1** | 今日のおすすめ学習 | 学習導線の最適化 |
| **P1** | セッション中断・再開 | スキマ時間利用の利便性 |
| **P2** | 紛らわしい選択肢生成（意味近接・形態類似） | 問題の質向上 |
| **P2** | 混同パターン学習 | 個人別のディストラクター最適化 |
| **P2** | ヒント機能 | 学習支援 |
| **P2** | オフライン対応 | 通信環境が悪い場面への対策 |
| **P3** | 出題方向のバリエーション（意味→単語） | 多角的な定着 |
| **P3** | 定着完了後の再出題（忘却防止） | 長期的な記憶維持 |
