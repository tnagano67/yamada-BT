# グレードアップ学習システム - 機能仕様統合レポート v2

## システム概要

| 項目 | 内容 |
|------|------|
| 対象 | 高校全校（生徒約1,000名、教員約60名） |
| 教科 | 英単語（1,900語・48グレード）、日本語（800語・20グレード） |
| 問題形式 | 4択（単語帳データから自動生成） |
| 端末 | 学校PC（メイン）+ スマホ対応（PWA） |
| 認証 | Google学校アカウント |

---

## 1. 朝テスト運用

### 教員の役割（60名中、日常操作は約32名）

| 役割 | 人数 | 日常作業 |
|------|------|---------|
| 教科主任 | 2名 | 学期初めに配信スケジュール設定（曜日パターン+休止期間） |
| HR担任 | 約30名 | 日2分（声かけ+結果確認） |
| その他 | 約28名 | 操作なし |

### 出題方式

- **生徒の現在グレードに応じた個別テストを自動配信**
- 4択問題は単語帳データから**完全自動生成**（教員の問題作成不要）
- 学期一括設定（30分/学期）で全週スケジュールを事前登録可能

### 朝テストのタイムライン

```
8:15  自動配信 + プッシュ通知
8:20  HR開始 → 生徒がテスト開始
8:23  テスト終了 → 即時結果表示
8:25  HR通常運営へ（全体5分で完了）
8:30  自動締切（配信15分後）
```

### グレードとの連動

- 朝テストは常にその生徒のグレード範囲から出題されるため、**常に昇格カウント対象**
- **先に進みたい生徒は自学自習モードでも並行して昇格可能**

## 2. 自学自習モード

### 3つの学習モード

| モード | 目的 | 問題数 | 所要時間 |
|--------|------|:------:|:--------:|
| **クイック練習** | 日常の語彙定着 | 10問 | 2〜3分 |
| **苦手克服** | 間違えた問題の復習 | 10問 | 2〜3分 |
| **昇格チャレンジ** | グレード昇格判定 | 10問 | 3分 |

### 昇格の仕組み（統合カウント方式）

```
朝テスト80%以上 → カウント+1
昇格チャレンジ80%以上 → カウント+1
3回連続で → 昇格！

※ 朝テスト2回 + 自学自習1回 = 昇格 も成立
※ 朝テストだけでも、自学自習だけでも昇格可能
```

- 昇格チャレンジは1日3回まで、受験条件フリー
- 不合格時はカウントリセットのみ（気軽に挑戦できる設計）

### 4択問題の工夫

- **3層ディストラクター**: 意味近接 / 形態類似 / ランダム の3層で誤答選択肢生成
- **消去法対策**: 品詞統一、文字数均一化、正解位置の均等配分
- 同じ問題でも毎回選択肢を変更、出題方向もバリエーション

### 苦手克服（修正Leitnerシステム）

| レベル | 復習間隔 |
|:------:|:--------:|
| Lv0 | 即日 |
| Lv1 | 翌日 |
| Lv2 | 3日後 |
| Lv3 | 7日後 |
| Lv4 | 14日後 |
| Lv5 | 定着完了（苦手リストから卒業） |

- 不正解 → Lv0に戻す（Lv3以上からはLv1へ。心理的負荷軽減）
- 最短5回連続正解で定着完了

### スキマ時間設計

- ワンタップ学習開始（おすすめカード → 10問 → 結果 = 13タップ、2〜3分）
- 中断・再開対応（24時間以内）
- オフラインファースト設計（問題データをローカルキャッシュ）

## 3. バッジ・ストリーク

### バッジ（初期リリース10個、3カテゴリ）

| # | バッジ名 | 条件 | 難易度 |
|---|---------|------|:------:|
| 1 | はじめの一歩 | 初回朝テスト受験 | ★ |
| 2 | ウィークリーマスター | 7日連続学習 | ★★ |
| 3 | マンスリーマスター | 30日連続学習 | ★★★★ |
| 4 | パーフェクトデイ | 朝テスト全問正解 | ★★ |
| 5 | 100問の壁突破 | 累計100問正答 | ★★ |
| 6 | 500問の壁突破 | 累計500問正答 | ★★★ |
| 7 | 1000問の壁突破 | 累計1000問正答 | ★★★★ |
| 8 | リベンジ成功 | 過去不正解の問題を3問正解 | ★★ |
| 9 | 昇格テスト一発合格 | 不合格なしで3回連続合格 | ★★★ |
| 10 | 苦手克服 | 正答率40%以下→75%以上に | ★★★★ |

- 1学期で平均5〜7個取得できるペース
- バッジの段階的開示（「???」→ 条件判明 → 取得）でワクワク感維持

### ストリーク

| ルール | 内容 |
|--------|------|
| カウント条件 | 授業日に朝テスト受験（正答率不問） |
| 土日祝 | 自動スキップ |
| 長期休暇 | 凍結保存（休暇明けに受験で継続） |
| フリーズ | 学期3回（30日達成で+1、上限5） |
| 復活チャレンジ | 学期2回（10問中8問正解で復活） |

### 炎アイコン（5段階）

```
Lv.0 (0日)    : 灰色の炎
Lv.1 (1〜6日)  : 小さなオレンジの炎
Lv.2 (7〜29日) : 中サイズの赤い炎
Lv.3 (30〜59日): 大きな赤い炎 + パーティクル
Lv.4 (60〜99日): 青い炎
Lv.5 (100日〜) : 虹色の炎
```

### グレード昇格演出

| 種類 | 演出時間 | 特徴 |
|------|:--------:|------|
| 通常昇格 | 約5秒 | カード出現 + 紙吹雪 |
| 復習グレードクリア | 約8秒 | ゴールドオーバーレイ +「ブロッククリア!」+ マスター語数表示 |
| 完全制覇（E48/J20） | 約15秒 | 虹色オーバーレイ + 一文字表示 + 学習日数 + 特別称号 |

## 4. ダッシュボード・管理機能

### 生徒ホーム画面

- 朝テスト配信時は最上部にフルワイドバナー（ワンタップで開始）
- ストリーク → グレード進捗 → レコメンドカード → 学期目標の優先順で配置
- PC: 2〜3カラム横並び / スマホ: 1カラム縦積み + 下部タブバー

### 教員ダッシュボード

- **今日のサマリー**: 配信テスト数、受験率、平均正答率
- **要注意アラート**: 6条件×3段階の重要度で自動生成
  - 高: 3日連続未受験 / 正答率3週連続低下 / 目標達成率20%未満
  - 中: ストリーク途切れ / 昇格テスト3回連続不合格
  - 低: 1週間自学自習なし
- **クラス詳細**: 概要/生徒一覧/テスト結果/分析の4タブ
- **個別生徒**: 成績推移グラフ、苦手分野、教員メモ
- **CSVエクスポート**: 4種類（テスト結果/問題別正答率/生徒別サマリー/学期末レポート）

### 学校管理機能

- **4段階の権限**: システム管理者 / 教科主任 / 担任教員 / 教科担当教員
- **クラス・生徒管理**: CSV一括登録、異動・転入・転出対応
- **学校カレンダー**: 授業日/祝日/考査期間/行事日の管理、ストリーク連動
- **学期目標の一括設定**: 学年目標 → システムが個人推奨を自動算出

### 通知設計

| 対象 | 通知 | デフォルト |
|------|------|-----------|
| 生徒 | 朝テスト配信 | プッシュON |
| 生徒 | 締切リマインダー（5分前） | プッシュON |
| 生徒 | 昇格・バッジ獲得 | アプリ内のみ |
| 教員 | テスト結果速報 | アプリ内 |
| 教員 | 要注意アラート | アプリ内 |
| 教員 | 日次サマリーメール | メール（任意） |

- 生徒プッシュ通知: 1日最大3回
- 全通知: 個別にON/OFF設定可能

### 年度更新

- **3フェーズ**: 準備（3月）→ 切替（4月1日）→ 事後（4月第1週）
- **引き継ぎ**: グレード・バッジ・累計正答数・復習リストは引き継ぎ
- **リセット**: ストリーク現在値・フリーズ・復活チャレンジ・学期目標
- **卒業生**: 成績3年保持、個人情報1年保持

## 5. 配慮事項まとめ

| 施策 | 内容 |
|------|------|
| **降格なし** | グレードは上がるのみ |
| **参加でストリーク** | 正答率不問、受験するだけでカウント |
| **個人ランキングなし** | 成績順位を表示しない |
| **成長バッジ** | 成績が低い生徒ほど取りやすい設計 |
| **フリーズ+復活** | ストリーク途切れへの救済措置 |
| **ポジティブな言葉** | 「不合格」→「もう少し!」 |
| **プレッシャー回避** | ストリーク途切れはプッシュ通知しない |
| **教師の個別調整** | 昇格条件やストリーク条件を個別に変更可能 |
| **グレード非公開** | 他の生徒へのグレード公開はデフォルトOFF |
| **炎で間接表現** | 具体的日数ではなく炎レベルで緩やかに可視化 |
