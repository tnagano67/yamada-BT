# グレード構成 詳細設計

## 基本ルール

- 1グレード = 50語（新出）
- 新出グレード4つごとに復習グレード（累計範囲）を配置
- 昇格条件: **3回連続 80%以上（10問中8問正解）**
- 復習グレードは、それまでの全範囲から出題

## 昇格条件

### 全グレード共通

```
そのグレード範囲の小テストで 3回連続 80%以上（10問中8問正解）
```

### 連続カウントのルール

- 合格（80%以上）→ カウント+1
- 不合格（80%未満）→ カウントを0にリセット
- 未受験の日 → カウントは維持（リセットしない）
- カウントが3に達した時点で即座に昇格

### 4択問題の自動生成ルール

- 出題: そのグレードの範囲から10問をランダム選出
- 正解: 1つ
- 誤答選択肢: 同じグレード範囲内の他の単語から3つ選出
- 復習グレードの場合: 全範囲からまんべんなく出題（偏りを防ぐ）
