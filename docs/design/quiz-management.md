# 小テスト・問題管理機能 詳細設計書

## 1. 概要

本システムは、英単語1,900語（48グレード: E1〜E48）および日本語800語（20グレード: J1〜J20）の単語帳マスタデータから、4択問題を自動生成して朝5分テストとして配信する。各グレードは50語単位で構成され、新出4グレードごとに復習グレード（累計範囲）が設けられている。

**運用規模:** 学校全体（生徒1,000名、教員60名）
**利用環境:** 学校PC（メイン）+ スマホ（PWA）、Google学校アカウントでログイン

---

## 2. 問題形式

### 2.1 4択問題（唯一の出題形式）

すべてのテストは4択形式で統一する。正解1つと誤答選択肢3つを提示し、生徒が1つを選択する。

- 記述式・マッチング・並べ替え・○×・フラッシュカード等の形式は採用しない
- 4択に統一することで、完全自動採点が可能となり、教員の採点負担をゼロにする
- 出題方向は英→和（英単語の意味を選ぶ）、和→英（日本語の意味に対応する英単語を選ぶ）の両方に対応

---

## 3. 問題の自動生成

### 3.1 基本ルール

問題は単語帳マスタデータから自動生成される。教員が手動で問題を作成する必要は基本的にない。

- 指定されたグレード範囲から**10問**をランダムに選出
- 各問について、正解1つ + 誤答選択肢3つを生成
- 誤答選択肢は同グレード範囲内から選出する
- 問題順および選択肢順をシャッフルして出題

### 3.2 誤答選択肢の3層戦略

誤答選択肢は以下の3層から生成し、適度な難易度と識別力を確保する。

| 層 | 戦略 | 説明 |
|----|------|------|
| 第1層 | 意味近接 | 正解と意味が近い単語を選出（例: big の誤答に large, tall, wide） |
| 第2層 | 形態類似 | 正解とスペルや音が似ている単語を選出（例: accept の誤答に except, expect） |
| 第3層 | ランダム | 同グレード範囲内からランダムに選出 |

### 3.3 復習グレードでの出題ルール

復習グレードでは以下の追加ルールを適用する。

- 対象となる各ブロック（過去のグレード群）から**均等に**問題を抽出
- 生徒が**過去に間違えた問題を30%優先出題**（個人の誤答履歴に基づく）

## 4. 配信管理（教員の役割）

### 4.1 自動配信の仕組み

朝テストは**生徒の現在グレードに応じて個別のテストが自動配信**される。教員による出題操作は基本的に不要。

- システムが各生徒の現在グレードを参照し、該当グレード範囲から10問を自動生成
  - 例: E5の生徒にはE5範囲（No.1〜200）から出題
  - 例: E8の生徒にはE8範囲（No.351〜400）から出題
- 問題は単語帳マスタから自動生成され、配信も自動で行われる
- 従来の「出題担当6名体制」は不要

### 4.2 教員が管理する項目

教科主任等が以下の**配信スケジュール設定**のみを行う。

- **曜日ごとの教科割り当て**: 月〜金に英語/国語をどう配分するか（例: 月水金=英語、火木=国語）
- **テスト休止期間の設定**: 定期テスト期間・学校行事等でテストを休止する期間の指定
- **配信時刻の確認・変更**: デフォルト8:15の配信時刻の調整（必要な場合のみ）

### 4.3 学期一括設定

- 学期の配信スケジュール（曜日ごとの教科割り当て、休止期間）を**事前に一括登録**可能
- 一括設定後の日常運用では教員の操作は**原則不要**
- スケジュール登録後も個別の日について休止・変更が可能

---

## 5. 配信

### 5.1 配信方式

- **全校一斉配信・生徒個別テスト**方式を採用する
- 毎朝の配信時間は学校として統一（デフォルト: 8:15）
- 各生徒には現在グレードに応じた**個別のテストが自動生成**される
- 同じクラスでも生徒ごとに出題されるグレード範囲・問題が異なる

### 5.2 自動配信スケジュール

| 項目 | 設定値 |
|------|--------|
| 配信時刻 | 8:15 自動配信 |
| 締切時刻 | 8:30 自動締切（配信から15分後） |
| 通知 | プッシュ通知で生徒に告知 |

### 5.3 配信ステータス

| ステータス | 説明 |
|-----------|------|
| draft | 下書き（未スケジュール） |
| scheduled | スケジュール済み（配信予約中） |
| active | 配信中（受験可能） |
| closed | 締切済み |

---

## 6. 朝5分テスト

### 6.1 テスト仕様

| 項目 | 設定値 |
|------|--------|
| 問題形式 | 4択 |
| 問題数 | 10問 |
| 制限時間 | 3分 |
| 受験回数 | 1回のみ |
| 結果表示 | 即時 |

### 6.2 時間配分モデル

```
全体5分（300秒）の内訳:
- アプリ起動・テスト開始: 30秒
- 問題解答（10問 x 約15秒）: 180秒（3分）
- 結果確認・復習:          90秒
```

---

## 7. 採点

4択問題のみのため、**完全自動採点**で運用する。

- 正解との一致判定のみ（正解の選択肢を選んだか否か）
- 記述式の表記ゆれ補正、手動採点等は一切不要
- 送信直後に採点結果を確定し、**即時フィードバック**を返す

---

## 8. データモデル

### 8.1 Word（単語帳マスタ）

```
Word {
  id: UUID
  word_number: number          // 単語番号（通し番号）
  word: string                 // 単語（英語 or 日本語）
  meaning: string              // 意味
  part_of_speech: string       // 品詞
  grade_id: UUID               // 所属グレード（E1〜E48, J1〜J20）
  category_tags: string[]      // カテゴリタグ（意味近接グループ等）
}
```

### 8.2 Quiz（小テスト）

```
Quiz {
  id: UUID
  title: string                // テスト名（例: "Week12 英単語テスト E5"）
  subject: string              // 教科（英語、国語）
  grade_id: UUID               // 対象グレード
  question_count: number       // 出題数（デフォルト: 10）
  time_limit_sec: number       // 制限時間（デフォルト: 180秒）
  shuffle_questions: boolean   // 問題順シャッフル（デフォルト: true）
  shuffle_options: boolean     // 選択肢シャッフル（デフォルト: true）
  passing_score: number        // 合格ライン（%）
  max_attempts: number         // 受験回数制限（朝テスト: 1）
  created_by: UUID             // 作成教員
}
```

### 8.3 QuizDistribution（配信設定）

```
QuizDistribution {
  id: UUID
  quiz_id: UUID
  target_type: string          // individual_auto | individual（補習用手動指定）
  student_id: UUID             // 対象生徒のID
  student_grade_id: UUID       // 配信時点の生徒の現在グレード
  scheduled_at: datetime       // 配信日時（デフォルト: 8:15）
  deadline_at: datetime        // 締切日時（デフォルト: 8:30）
  is_morning_test: boolean     // 朝テストフラグ
  status: string               // draft | scheduled | active | closed
}
```

> **補足:** 朝テストでは `target_type: individual_auto` が使用され、システムが全生徒分の配信レコードを自動生成する。各レコードは生徒1名に対応し、その生徒の現在グレードに基づく問題が紐づく。

### 8.4 QuizAttempt（受験記録）

```
QuizAttempt {
  id: UUID
  quiz_distribution_id: UUID
  student_id: UUID
  started_at: datetime
  submitted_at: datetime
  score: number                // 得点（正解数）
  score_percentage: number     // 正答率（%）
  is_passed: boolean           // 合格判定
}
```

### 8.5 Answer（回答詳細）

```
Answer {
  id: UUID
  attempt_id: UUID             // QuizAttempt.id
  word_id: UUID                // 出題された単語（Word.id）
  question_direction: string   // 出題方向（word_to_meaning | meaning_to_word）
  correct_option: string       // 正解の選択肢
  selected_option: string      // 生徒が選択した選択肢
  all_options: string[]        // 表示された全選択肢（4つ）
  is_correct: boolean          // 正誤
}
```

## 9. 結果表示

### 9.1 生徒向け（即時フィードバック）

**テスト直後の結果画面:**
- 得点 / 満点（例: 8/10）
- 正答率（例: 80%）
- 合格 / 不合格の表示
- 昇格カウント状況（グレード昇格までの残回数）

**問題別の振り返り:**
- 各問の正誤マーク
- 自分の回答と正解の対比
- 間違えた問題を「復習リスト」に自動追加

### 9.2 教員向け（ダッシュボード）

**クラス・学年全体の概要:**
- 受験率（受験者数 / 対象者数）
- グレード別の受験者数・合格率（各グレードに何名が取り組み、何名が合格したか）
- グレード別の平均正答率
- 未受験者リスト

> **補足:** 生徒個別配信のため、クラス内で出題される問題が異なる。従来の「問題別正答率」に代わり、グレード単位での集計を基本とする。

**データエクスポート:**
- CSV形式でダウンロード（成績一覧、グレード別合格率）
