# グレード制度・ゲーミフィケーション設計書

> 本書はグレード制度・ゲーミフィケーション全体の概要設計書です。各機能の詳細は個別設計書を参照してください。

---

## 1. グレード構成

### 1.1 基本方針

- **教科別グレード制**を採用（英単語・日本語を独立管理）
- 教科ごとに得意・不得意が異なるため、片方が低くてもモチベーションを維持できる
- 50語/グレードの固定単位で、学習範囲が明確

### 1.2 グレード一覧

| 教科 | 総語数 | 語数/グレード | グレード数 | グレード範囲 |
|------|--------|-------------|-----------|------------|
| 英単語 | 1,900語 | 50語 | 48 | E1 〜 E48 |
| 日本語 | 800語 | 50語 | 20 | J1 〜 J20 |

### 1.3 新出・復習パターン

新出4グレード + 復習1グレードの5グレード周期で構成する。

| グレード | 範囲 | 種別 |
|---------|------|------|
| E1 | 1-50 | 新出 |
| E2 | 51-100 | 新出 |
| E3 | 101-150 | 新出 |
| E4 | 151-200 | 新出 |
| E5 | 1-200 | 復習（累計範囲） |
| E6 | 201-250 | 新出 |
| ... | ... | ... |

日本語（J1〜J20）も同パターン。

> 詳細: [docs/design/grade-structure.md](design/grade-structure.md)

## 2. 昇格条件

### 2.1 基本ルール

**3回連続80%以上（10問中8問正解）で昇格。**

| 項目 | 内容 |
|------|------|
| 昇格条件 | 3回連続で正答率80%以上 |
| 出題数 | 1回あたり10問 |
| 合格ライン | 8問以上正解 |

### 2.2 統合カウント方式

朝テストと自学自習の昇格チャレンジを同一カウントとして扱う。

| シナリオ | カウント |
|---------|---------|
| 朝テスト80%以上 → 朝テスト80%以上 → 自学自習80%以上 | 3回連続達成 → **昇格** |
| 朝テスト80%以上 → 朝テスト60% | カウント**リセット**（0に戻る） |
| 朝テスト80%以上 → 翌日未受験 → 朝テスト80%以上 | カウント**維持**（2回目として加算） |

### 2.3 ルールまとめ

- 不合格（80%未満）でカウントリセット
- 未受験日はカウント維持（リセットしない）
- **降格なし** -- 一度到達したグレードは下がらない

## 3. バッジシステム

### 3.1 初期リリース（10個・3カテゴリ）

#### 継続バッジ（3個）

| バッジ名 | 条件 |
|---------|------|
| はじめの一歩 | 初回テスト完了 |
| ウィークリーマスター | 7日連続学習 |
| マンスリーマスター | 30日連続学習 |

#### 実力バッジ（4個）

| バッジ名 | 条件 |
|---------|------|
| パーフェクトデイ | 1日の小テスト全問正解 |
| 100問の壁突破 | 累計100問正答 |
| 500問の壁突破 | 累計500問正答 |
| 1000問の壁突破 | 累計1000問正答 |

#### 成長バッジ（3個）

| バッジ名 | 条件 |
|---------|------|
| リベンジ成功 | 過去に間違えた問題を3回連続正答 |
| 昇格テスト一発合格 | 昇格チャレンジに初回挑戦で合格（3回連続を一度も途切れずに達成） |
| 苦手克服 | 正答率30%以下だったカテゴリが70%以上に |

> 詳細: [docs/design/badge-streak-design.md](design/badge-streak-design.md)

## 4. ストリーク設計

### 4.1 カウント方法

| ルール | 内容 |
|--------|------|
| カウント対象 | 授業日に朝テストを受験（正答率不問） |
| 土日祝 | 自動スキップ（カウントに影響しない） |
| 長期休暇 | 凍結保存（ストリークを維持したまま停止） |

### 4.2 フリーズ制度

| 項目 | 内容 |
|------|------|
| 初期回数 | 学期あたり **3回** |
| 追加獲得 | 30日連続達成ごとに +1回 |
| 上限 | **5回** |

### 4.3 復活チャレンジ

- 学期あたり **2回** まで利用可能
- ストリーク途切れ時に挑戦し、成功すればストリーク継続

### 4.4 炎アイコン（5段階）

| レベル | アイコン | 条件（目安） |
|--------|---------|------------|
| 0 | 灰 | ストリークなし |
| 1 | オレンジ | ストリーク開始 |
| 2 | 赤 | 7日以上 |
| 3 | 青 | 30日以上 |
| 4 | 虹 | 60日以上 |

> 詳細: [docs/design/badge-streak-design.md](design/badge-streak-design.md)

## 5. 学期目標

### 5.1 目標設定フロー

1. 学期開始時にシステムが**推奨目標を自動提案**
2. 生徒は推奨目標を採用、または自分で調整して設定
3. 担任教師が目標一覧を確認し、必要に応じて個別にアドバイス

### 5.2 中間チェックポイント

学期の中間地点（6〜7週目）で自動的に進捗チェックを実施。

- **順調**: 励ましメッセージ
- **やや遅れ**: 具体的なアドバイス
- **要注意**: 目標見直しの提案

### 5.3 学期末評価

達成度に応じたリワードを付与。

| 達成度 | リワード |
|--------|---------|
| 100%以上 | 特別バッジ + 称号解放 |
| 80〜99% | 「惜しかった！」バッジ |
| 50〜79% | 参加バッジ |
| 50%未満 | 励ましメッセージ |

## 6. ダッシュボード

### 6.1 生徒個人ダッシュボード

- **グレードカード**: 各教科の現在グレード + 次グレードまでの進捗
- **ストリーク表示**: 炎アイコン + 連続日数
- **レコメンド**: 学習のおすすめ（復習すべき範囲など）
- **学期目標進捗**: 目標グレードまでの到達度

### 6.2 クラスダッシュボード（生徒向け）

- 匿名のグレード分布（棒グラフ）
- クラス平均グレード・正答率
- **個人ランキングは非表示**

### 6.3 教師ダッシュボード

- クラス一覧（平均グレード・正答率・ストリーク）
- 個別生徒データ（グレード・正答率・ストリーク・学期目標進捗）
- 要注意アラート（ストリーク途切れ・正答率低下・目標大幅未達）
- データ分析（苦手傾向・出題調整提案）

> 詳細: [docs/design/dashboard-and-admin.md](design/dashboard-and-admin.md)

## 7. 配慮事項

### 7.1 基本方針

生徒のモチベーションを守り、過度な競争やプレッシャーを避ける設計とする。

| 対策 | 詳細 |
|------|------|
| **降格なし** | 一度到達したグレードは下がらない |
| **参加でストリーク** | ストリークのカウント条件は受験のみ（正答率不問） |
| **個人ランキング非表示** | 生徒向けダッシュボードに順位を表示しない |
| **成長バッジの設計** | 成績が低い生徒ほど取りやすい（リベンジ成功・苦手克服など） |
| **フリーズ・復活** | ストリーク途切れの救済措置を複数用意 |
| **ポジティブな表現** | 「不合格」ではなく「もう少し」、「失敗」ではなく「次の挑戦へ」 |
| **グレードデフォルト非公開** | 自分のグレードを他の生徒に表示するかはデフォルトで非公開 |
| **教師による個別調整** | 特別な事情に応じて昇格条件やストリーク条件を教師が調整可能 |

## 8. データモデル概要

### student_grade（生徒グレード）

```
student_grade:
  - student_id (FK)
  - subject (英単語 / 日本語)
  - current_grade (E1〜E48 / J1〜J20)
  - promotion_consecutive_passes (0〜3: 連続合格回数)
```

### student_streak（ストリーク）

```
student_streak:
  - student_id (FK)
  - current_streak (現在の連続日数)
  - max_streak (最長連続日数)
  - freeze_remaining (残りフリーズ回数)
  - revival_remaining (残り復活チャレンジ回数)
  - flame_level (0〜5: 炎レベル)
```

### badge_master / student_badge（バッジ）

```
badge_master:
  - id (PK)
  - name (バッジ名)
  - category (継続 / 実力 / 成長)
  - condition (取得条件)

student_badge:
  - student_id (FK)
  - badge_id (FK)
  - earned_at (取得日時)
```

### semester_goal（学期目標）

```
semester_goal:
  - student_id (FK)
  - semester_id (FK)
  - subject (英単語 / 日本語)
  - target_grade (目標グレード)
  - current_progress (現在の進捗)
  - status (進行中 / 達成 / 未達成)
```
